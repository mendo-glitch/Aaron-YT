PINNACLE — "5 SIGNS YOU'RE NOT READY TO RETIRE"
Thumbnail graphics, transparent PNG
------------------------------------------------

Every file is a full-frame 1920x1080 RGBA overlay. Drop it on a layer above
your footage and it lines up — no repositioning needed. Scale the whole layer
if your canvas is 4K or 1280x720.

FOLDERS

  with-shadow/       As designed. The drop shadow is what holds white type
                     over the light brick wall — keep this unless you are
                     adding your own.

  no-shadow/         Same artwork, shadows stripped. Use if you want to build
                     the shadow in your NLE or go without.

  separated-layers/  Concept 01 broken into badge / headline / marks so each
                     can be moved independently. Each is also full-frame, so
                     stacking all three reproduces the composite exactly.

CONCEPTS

  02  ONLY 2 ARE ABOUT MONEY
  03  STILL NOT READY

TYPE + COLOUR

  need to set additional copy to match.

NOTE ON PLACEMENT

  The layout assumes Aaron sits left of centre, with the type column starting
  around 51% of frame width. If you reframe him, the separated layers give you
  room to move without re-rendering.
